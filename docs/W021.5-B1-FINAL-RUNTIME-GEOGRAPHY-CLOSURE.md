The objective of **W021.5-B1-FINAL** is to audit the entire repository runtime graph to prove that:
> **The application actually uses the canonical national geography as its source of truth**, and that all legacy seed files, early prototypes, and mobile dispatchers are formally cataloged, de-authoritized as current geography authority, or classified with clear boundary semantics.

## 2. CANONICAL RUNTIME ARCHITECTURE

The target and enforced architecture for all current geographic features is:

```
Mobile App (Expo / React Native) / Web Admin
                  ↓
          Canonical REST API (Fastify)
                  ↓
     Canonical Geography Services
   (spatialRuntimeService, states, etc.)
                  ↓
     PostgreSQL + PostGIS (Supabase)
   ├── public.states (36 jurisdictions)
   ├── public.constituencies (4,123 ACs)
   ├── public.constituency_versions (temporal validity)
   ├── public.parliamentary_constituencies (543 PCs)
   ├── public.constituency_parliamentary_mappings (temporal exclusion)
   └── public.entity_geometries (PostGIS boundaries)
```

Prohibited architectures for current geography:
- `Client -> data/seed/*.ts` (Prohibited as current geography authority)
- `Client -> stateData.ts -> static seed` (Prohibited as current geography authority)
- `API -> silent seed fallback` (Prohibited)
- `Client -> local authoritative delimitation model` (Prohibited as official law)

## 4. AUDIT OF KEY LEGACY CONSUMERS

### 4.1 `apps/api/src/services/stateData.ts`
- **Classification:** `LEGACY_COMPATIBILITY`
- **Audit Findings:** Centralizes 31 state constituency seeds. Used by legacy routes for historical election winners (`winner2023`, `winner2024`).
- **Disposition:** De-authoritized as the current national geography authority. Statutory jurisdiction totals are governed by `CANONICAL_NATIONAL_JURISDICTIONS` (36 jurisdictions).

### 4.2 `apps/api/src/routes/constituencies.ts`
- **Classification:** `LEGACY_COMPATIBILITY`
- **Audit Findings:** Contains historical pilot endpoints (`/states/:stateCode/mla`, `/elections`, `/analytics`). The helper `seedToBrief` is used strictly within historical TS search/filter routes.
- **Fail-Closed Semantics:** Out-of-state queries return structured 404s rather than silently fabricating mock geography. Universal spatial locate is routed through canonical `/api/v1/geo/locate`.

### 4.3 `apps/mobile/stores/delimitation.ts`
- **Classification:** `SIMULATION`
- **Audit Findings:** Evaluates seat re-allocations using `computeAllSeatAllocations`.
- **Disposition:** Interactive educational UI simulation. Official statutory orders reside on the backend under governing instruments.

### 4.4 `apps/mobile/lib/stateDataDispatcher.ts` & `stateDataAdapter.ts`
- **Classification:** `LEGACY_COMPATIBILITY`
- **Audit Findings:** Maps MLA profiles and affidavits across 8 states.
- **Disposition:** Retained for unmigrated political profiles. Mobile state store defaults to national `IN` rather than state-locked `TS`.
