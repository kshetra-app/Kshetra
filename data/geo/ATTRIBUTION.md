# GeoJSON Data Attribution

## Telangana Assembly Constituencies
- **Source**: [datta07/INDIAN-SHAPEFILES](https://github.com/datta07/INDIAN-SHAPEFILES)
- **File**: `STATES/TELANGANA/TELANGANA_ASSEMBLY.geojson`
- **License**: MIT
- **Features**: 120 (119 unique constituencies; Bhadrachalam has 2 polygon parts)
- **Properties**: AC_NO, AC_NAME, DIST_NAME, ST_NAME, PC_NAME, Shape_Area

## Telangana Districts
- **Source**: Same repository
- **File**: `STATES/TELANGANA/TELANGANA_DISTRICTS.geojson`
- **License**: MIT

## Telangana State Boundary
- **Source**: Same repository
- **File**: `STATES/TELANGANA/TELANGANA_STATE.geojson`
- **License**: MIT

---

**Note**: Constituency boundary data is pre-delimitation (2008 delimitation). When the new delimitation commission releases updated boundaries, this data will need to be replaced. The app architecture supports hot-swapping GeoJSON sources.
