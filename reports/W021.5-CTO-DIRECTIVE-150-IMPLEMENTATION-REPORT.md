## 2. Workstream 1 (P0) — Stage 1 Authorization Integrity & Fail-Closed Execution Gate

### 2.1 Explicit Stage 1 Authorization Gate (`isStage1Authorized`)
File: `scripts/execute_staging_directive_139.mjs`

To resolve the unreachable write branch defect, `executeStage1Staging` now evaluates `isStage1Authorized(internalContext)` before any network request or reconciliation step:

```javascript
function isStage1Authorized(internalContext) {
  if (!internalContext || !internalContext.authGrant) {
    return false;
  }
  const grant = internalContext.authGrant;

  // 1. Administrator containment must be confirmed
  if (grant.adminContainmentConfirmed !== true) {
    return false;
  }

  // 2. CRIT-C02-02 must be explicitly granted
  if (!grant.criteria || !grant.criteria.has('CRIT-C02-02')) {
    return false;
  }

  // 3. SELECT operation must be explicitly granted for target-state retrieval
  if (!grant.operations || !grant.operations.has('SELECT')) {
    return false;
  }

  // 4. Write operations must be explicitly granted (INSERT + UPDATE or UPSERT)
  const hasWrites = (grant.operations.has('INSERT') && grant.operations.has('UPDATE')) || grant.operations.has('UPSERT');
  if (!hasWrites) {
    return false;
  }

  // 5. All 8 Stage 1 tables must be explicitly granted
  for (const table of STAGE1_TABLE_SEQUENCE) {
    if (!grant.tables || !grant.tables.has(table)) {
      return false;
    }
  }

  return true;
}
```

When authorization is absent, incomplete, or granted only for Stage 2 (such as `CRIT-D02-02` on `candidacies`), Stage 1 returns:

### 2.2 Target State Retrieval Fail-Closed Semantics & Range Pagination
File: `scripts/execute_staging_directive_139.mjs`

`fetchTargetDatabaseState` implements strict fail-closed error handling and complete PostgREST pagination:
- **HTTP Fail-Closed:** Non-2xx responses (including 403 Forbidden, 500 Internal Error, 502 Bad Gateway, 404 Not Found) throw `TARGET_STATE_READ_FAILED` with the HTTP status and response body.
- **Malformed Response:** Non-JSON or truncated responses throw `TARGET_STATE_MALFORMED_JSON`.
- **Network Failures:** Connection resets and socket timeouts throw `TARGET_STATE_NETWORK_ERROR`.
- **Range Pagination Headers:** Dispatches requests with `Range: offset-(offset + pageSize - 1)`, `Range-Unit: items`, and `Prefer: count=exact`.
- **Content-Range Completeness:** Parses the total count from `Content-Range: 0-499/1043`. If the loop terminates with retrieved rows not equal to `totalCount`, it throws `TARGET_STATE_INCOMPLETE_PAGINATION`.
- **1,043 Organization Aliases:** Successfully retrieves all 1,043 aliases across 3 consecutive pages (0-499, 500-999, 1000-1042) without truncation.

### 2.3 Retry-Safe Mutations & Exact Row Validation
File: `scripts/execute_staging_directive_139.mjs`

When executing authorized mutations:
- **POST Inserts:** Requests specify `Prefer: return=representation`. The response row count is asserted against the insert batch length. Any mismatch throws `STAGE_1_ROW_COUNT_MISMATCH`.
- **PATCH Updates:** Updates specify `Prefer: return=representation`. If the response array is empty (0 modified rows), it throws `STAGE_1_UPDATE_TARGET_NOT_FOUND`.

  ```sql
  SELECT TRUE, (conrelid = 'public.candidacies'::regclass AND
                confrelid = 'public.election_contests'::regclass AND
                confdeltype = 'r' AND
                convalidated = true)
  INTO v_exists, v_valid
  FROM pg_constraint
  WHERE conname = 'fk_candidacies_contest'
    AND conrelid = 'public.candidacies'::regclass;

  IF v_exists AND NOT v_valid THEN
    ALTER TABLE public.candidacies DROP CONSTRAINT fk_candidacies_contest;
    v_exists := FALSE;

  IF NOT v_exists THEN
    ALTER TABLE public.candidacies
  ```
