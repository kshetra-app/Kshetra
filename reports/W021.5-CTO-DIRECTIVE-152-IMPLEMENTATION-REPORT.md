## 5. P1 — Target-State Pagination Strict Fail-Closed Hardening

### 5.1 Fail-Closed Pagination Implementation
Rewrote `fetchTargetDatabaseState()` in `scripts/execute_staging_directive_139.mjs`:
- **Mandatory `Content-Range` Header:** Every successful response must provide a valid `Content-Range` header; otherwise throws `TARGET_STATE_MISSING_CONTENT_RANGE`.
- **Wildcard Total Rejection:** Headers with wildcard total (e.g. `0-499/*`) throw `TARGET_STATE_WILDCARD_TOTAL_FORBIDDEN`.
- **Malformed Range Syntax:** Malformed syntax throws `TARGET_STATE_MALFORMED_CONTENT_RANGE`.
- **Empty Table Handling:** Valid empty tables must have `Content-Range: */0` and return an empty array `[]`. If non-empty rows are returned with `*/0`, throws `TARGET_STATE_INVALID_EMPTY_RESPONSE`.
- **Range Boundary Verification:** Validates `rangeStart === offset` and `rangeEnd === offset + rows.length - 1`; otherwise throws `TARGET_STATE_PAGINATION_RANGE_INVALID`.
- **Total Count Consistency:** Compares `totalCount` across pages. Any mid-stream count mutation throws `TARGET_STATE_PAGINATION_TOTAL_CHANGED`.
- **Overlap & Duplication Detection:** Maintains a set of observed row IDs. Any duplicate row ID across pages throws `TARGET_STATE_PAGINATION_OVERLAPPING_ROWS`.
- **Complete Table Verification:** Requires all 8 Stage 1 tables to be retrieved; any missing table throws `TARGET_STATE_INCOMPLETE_TABLE_SET`.
