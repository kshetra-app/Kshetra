## 7. Application Consumer Compatibility & Nullability Hardening

Directive 064 §10 required an exhaustive audit of all mobile application consumers to prevent runtime exceptions when `total_assets` is `NULL` (undisclosed).

### 7.1 Consumer Audit Matrix Summary
The complete audit is recorded in `reports/w021_5_application_consumer_compatibility_matrix.json`:
1. `apps/mobile/lib/affidavitTypes.ts`:
   - **Vulnerability:** `formatINR(amount: number)` assumed non-null; `(null).toLocaleString('en-IN')` crashes; `computeWealthGrowth` returned `NaN` if either asset was null.
   - **Remediation:** `formatINR` updated to accept `number | null | undefined` and return `'Not Disclosed'` when nullish. `computeWealthGrowth` checks `older.totalAssets != null && newer.totalAssets != null` before arithmetic.
2. `apps/mobile/components/MLACard.tsx`:
   - **Vulnerability:** Local `formatINR(amount: number)` threw `TypeError` on null; card condition `{profile.totalAssets !== undefined && ...}` allowed `null` to pass through to formatter.
   - **Remediation:** `formatINR` hardened to handle nullish values and return `'Not Disclosed'`; card condition strengthened to `{profile.totalAssets != null && ...}`.
3. `apps/mobile/components/MPCard.tsx`:
   - **Vulnerability:** Local `formatINR(val: number)` threw `TypeError` on null; card condition `{profile.totalAssets !== undefined && ...}` allowed `null` to pass through.
   - **Remediation:** `formatINR` hardened to handle nullish values; card condition strengthened to `{profile.totalAssets != null && ...}`.
4. `apps/mobile/components/CandidateAffidavitCard.tsx`:
   - **Status:** Already null-safe (`formatCurrency(val)` gracefully handles null/undefined).
5. `apps/mobile/app/mla/[id].tsx` & `apps/mobile/app/mp/[id].tsx`:
   - **Status:** Safely uses optional chaining and displays placeholder text when data is missing.
