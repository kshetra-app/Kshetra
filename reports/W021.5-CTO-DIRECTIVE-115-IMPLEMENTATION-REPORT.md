## 2. Directive 115 Section 1 — Governance Workflow Remediation

### 2.1 Shallow Clone Root Cause & Fix
In CI run `39290879767`, the `Governance & Drift Integrity` job failed at step `Verify Governance Consistency` with:
```text
fatal: bad revision '795b9af'
AssertionError [ERR_ASSERTION]: Amendment v1.5 ratification commit 795b9af must exist in Git history
```
GitHub Actions' default `actions/checkout@v4` uses `fetch-depth: 1`, creating a shallow clone containing only the current tip. The governance consistency test requires traversing Git history to verify the cryptographic immutability of parent ratification commits (`795b9af`).

**Remediation:**
In `.github/workflows/ci.yml` (lines 18-21), configured full Git history fetching:
```yaml
      - name: Checkout
        uses: actions/checkout@v4
        with:
          fetch-depth: 0
```
