## 5. P0: Asymmetric Cryptographic Scope Hardening

Hardened [`scripts/lib/stagingAuthorization.mjs`](file:///c:/Users/Laven/OneDrive/Desktop/Kshetra/scripts/lib/stagingAuthorization.mjs) with strict claims validation:

1. **Temporal Claim Hardening:**
   - `iat`: Mandatory positive integer. Rejects missing or non-numeric `iat` with `INVALID_IAT`.
   - Future Issuance: Enforces that `iat <= now + 60s` (allowing 60-second clock skew). Future issuance throws `TOKEN_ISSUED_IN_FUTURE`.
   - Expiry vs Issuance: Enforces `exp > iat`. Expiry before or equal to issuance throws `INVALID_EXPIRY_BEFORE_ISSUANCE`.
   - Contradictory `nbf`: Rejects `nbf > exp` with `CONTRADICTORY_TIME_CLAIMS`.
   - Inconsistent `nbf`: Rejects `nbf < iat - 60s` with `INCONSISTENT_TIME_CLAIMS`.
   - Not Yet Valid: Rejects `nbf > now` with `TOKEN_NOT_YET_VALID`.
   - Maximum Lifetime: Enforces that both `(exp - iat)` and `(exp - nbf)` do not exceed 3,600 seconds (1 hour). Exceeding throws `EXCESSIVE_TOKEN_LIFETIME`.
2. **Proactive Rejection of Prohibited Destructive Operations:**
   - Defines `PROHIBITED_DESTRUCTIVE_OPERATIONS = ['DELETE', 'DROP', 'TRUNCATE', 'ALTER']`.
   - Rejects any token granting any prohibited destructive operation with `PROHIBITED_DESTRUCTIVE_OPERATION_IN_TOKEN`.
   - Prohibits operations outside the closed allowlist (`INSERT`, `UPDATE`, `UPSERT`, `SELECT`) with `UNAUTHORIZED_OPERATION_GRANT`.
3. **Closed Table Scope Enforcement:**
   - Defines `ALL_AUTHORIZED_STAGING_TABLES` (11 tables across all 4 stages):
     - `public.datasets`
     - `public.dataset_versions`
     - `public.provenance_records`
     - `public.political_organizations`
     - `public.organization_relationships`
     - `public.organization_multilingual_names`
     - `public.organization_symbols`
     - `public.organization_aliases`
     - `public.candidacies`
     - `public.constituency_demographics`
     - `public.election_results`
   - Rejects any token granting tables outside this allowlist with `UNAUTHORIZED_TABLE_GRANT`.
   - Rejects execution if requested tables exceed token grants with `UNAUTHORIZED_TABLE`.
