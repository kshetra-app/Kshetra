## 1. Executive Summary

Under **CTO Directive 085**, an independent, evidence-based audit and remediation was performed across national political-data coverage claims, electoral API contract semantics, historical election availability, and mobile data-source precedence.

Directive 084 integrated the mobile journey with the Fastify API and generated a national coverage matrix, but made unsupported completeness claims (promoting 4 states to `CANONICAL_FULL` based purely on state-code allowlists, inferring historical election years without per-constituency data, and defaulting missing election years to 2024).

Directive 085 successfully remediates these defects:
1. **National Coverage Inventory Overhaul:** Replaced naive regex matching and hardcoded allowlists in `scripts/generate_national_data_coverage_matrix.mjs` with schema-aware, multi-dimensional evidence auditing. Under Rule IV-001, `canonicalFullStatesCount` is set strictly to `0` because no state has verified live database backing or full affidavit coverage.
2. **Truthful Election API Contracts:** In `apps/api/src/services/stateData.ts` and `apps/api/src/routes/constituencies.ts`, removed all unjustified defaults (including the 2024 fallback for missing election years). `electionYear` is now typed as `number | null`, `electionType` is strictly validated to `'GENERAL' | 'BYPOLL'`, margin percentages are computed strictly when inputs exist, and `elections[]` records are chronologically sorted descending.
3. **Deprecation & Consumer Audit of `election2023`:** Inventoried all consumers of the legacy `election2023` alias. Confirmed that internal mobile screens have completely decoupled from `election2023` and consume `recentElection` and `elections[]`. Documented the safe backward-compatible migration path in `reports/W021.5-COMPATIBILITY-CONSUMER-IMPACT-REPORT.md`.
4. **Mobile Provenance Truthfulness:** In `apps/mobile/app/constituency/[id].tsx`, eliminated the misleading `"Verified Live API"` badge for mixed-source profiles, replacing it with `"Live API (Electoral) + Seed Data"`. Eliminated the `?? 2024` fallback for constituency election headings and router navigation.
5. **Canonical Architecture Gap Register:** Authored `reports/W021.5-CANONICAL-ARCHITECTURE-GAP-REGISTER.md` evaluating the 10 mandated domains and auditing `DATA_ARCHITECTURE.md` to flag obsolete claims, unsafe source heuristics (e.g. inferring caste from reservation), and ghost infrastructure.

## 3. Workstream Details

### Workstream A — Correct the National Coverage Inventory
- **Hardcoded Tiers Removed:** Completely removed `if (code === 'TS' || code === 'AP' || code === 'KA' || code === 'MH') { dataTier = 'CANONICAL_FULL'; ... }`.
- **Dimensional Separation:**
  1. *Registry / Identity:* Unique valid ACs vs statutory seats (4,123 total across 31 states). Missing, duplicate, and out-of-range checks.
  2. *Electoral Results:* Candidate winner and runner-up availability; vote counts and margins preserved with null distinction.
  3. *Historical Coverage:* Only actual per-constituency data files are credited (8 states: TS: [2018, 2014], AP: [2019], KA: [2018], MH: [2019], TN: [2016], KL: [2016], WB: [2016], UP: [2017]; 23 states: []).
  4. *Representative Profiles:* 3,913 unique valid profiles resolving to statutory assembly seats.
  5. *Affidavits:* 28 total affidavits across 8 states (TS: 17, AP: 2, KA: 2, MH: 1, TN: 2, KL: 1, WB: 1, UP: 2). Zero production verification.
  6. *Geospatial:* Only Telangana (`TS`) has valid GeoJSON in `data/geo`.
  7. *Provenance:* Source citations recorded; classified as `OFFLINE_LOCAL_FIXTURE`.
- **Evidence-Based Summary:**
  - `canonicalFullStatesCount`: **0** (Strictly zero under Rule IV-001).
  - `partialLocalWithGeoCount`: **1** (TS).
  - `partialHistoricalNoGeoCount`: **7** (AP, KA, MH, TN, KL, WB, UP).
  - `seededSingleTermCount`: **23** (All remaining states/UTs).
  - `unavailableCount`: **0**.
- **Delhi Statutory Boundary Invariant:** Strictly 70 statutory seats (`DL-AC-001` to `DL-AC-070`). 151 extra municipal/demographic records in `delhi-demographics.ts` (`DL-AC-071` to `DL-AC-221`) are explicitly isolated as `NON_STATUTORY_DEMOGRAPHIC_PLACEHOLDER`.

### Workstream B — Enforce Truthful Election API Contracts
- **Elimination of Guessed Defaults:** Removed `let year = 2024` and `else year = 2024` in `apps/api/src/services/stateData.ts`. Initialized to `let year: number | null = null`.
- **Schema & DTO Nullability:**
  - `recentElection.electionYear`: `{ type: ['integer', 'null'] }`.
  - `recentElection.electionType`: `{ type: 'string', enum: ['GENERAL', 'BYPOLL'] }`.
  - Mobile client `ConstituencyElectionSummary.electionYear`: `number | null`.
- **Margin Percent Calculation Guard:**
  - Only calculated if `winnerVotes != null && winnerVotes > 0 && margin != null && margin >= 0`. Otherwise strictly `null`.
- **Chronological Sorting:**
  - `elections[]` array sorted chronologically in descending order: `elections.sort((a, b) => (b.electionYear ?? 0) - (a.electionYear ?? 0))`.
- **Legacy `election2023` Alias:**
  - Documented as `@deprecated` in route schema and handler.
  - Full consumer audit completed in `reports/W021.5-COMPATIBILITY-CONSUMER-IMPACT-REPORT.md`.

### Workstream C — Mobile Source Precedence & Truthful Provenance
- **Truthful Provenance Badge:**
  - Previously displayed `"Verified Live API"` even when demographics and MLA profiles originated from offline seeds.
  - Now displays:
    * `"Live API (Electoral) + Seed Data"` when API response succeeds.
    * `"Offline Seed Data"` when API call fails and local seed is used.
    * `"Data Unavailable"` when missing from both.
- **Null Election Year Presentation:**
  - In `constituency/[id].tsx`, replaced `?? 2024` with `effectiveElectionYear ? ... : 'Recent Election Result'`.
  - Passed `effectiveElectionYear ?? undefined` to `AffidavitCard` and child cards without runtime crash.
- **SequenceGuard Integrity:** Verified that rapid navigation discards stale responses via `token.isStale()`.

### Workstream D — Canonical Architecture Gap Register & DATA_ARCHITECTURE.md Audit
- Produced `reports/W021.5-CANONICAL-ARCHITECTURE-GAP-REGISTER.md` covering all 10 mandated domains.
