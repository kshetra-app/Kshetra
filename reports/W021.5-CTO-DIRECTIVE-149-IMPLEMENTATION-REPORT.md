## 2. Workstream A — Schema-Contract & Foreign Key Constraint Reconciliation

### 2.1 Forward-Only Migration 069
File: `supabase/migrations/069_candidate_referential_integrity_reconciliation.sql` (SHA-256: `584f88effe438ace59f3a7acd6d9bfe925b7307f95a042e5477ae5d91f68d678`)

To resolve the defect where Directive 148 edited Migration 067 in place (which existing environments that already applied Migration 067 would skip), Migration 069 was added as a forward-only migration. It performs:
- **Idempotent Dropping of Obsolete Constraints:** Drops legacy `candidacies_contest_id_fkey` (`ON DELETE CASCADE`) and unnamed constraints on `person_id` and `party_id`.
- **Creation of Authoritative Named RESTRICT Constraints:**
  - `fk_candidacies_contest`: `FOREIGN KEY (contest_id) REFERENCES public.election_contests(id) ON DELETE RESTRICT`
  - `fk_candidacies_person`: `FOREIGN KEY (person_id) REFERENCES public.persons(id) ON DELETE RESTRICT`
  - `fk_candidacies_party`: `FOREIGN KEY (party_id) REFERENCES public.political_organizations(id) ON DELETE RESTRICT`
- **Index Deduplication:** Checks for duplicate redundant indexes (`idx_candidacies_contest_fk`, `idx_candidacies_person_fk`, `idx_candidacies_party_fk`) and safely drops them only when primary indexes (`idx_candidacies_contest`, `idx_candidacies_person`, `idx_candidacies_party`) exist.
