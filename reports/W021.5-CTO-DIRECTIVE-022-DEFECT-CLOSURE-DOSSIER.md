## SECTION 2: ROOT-CAUSE ANALYSIS & HARDENED FIX BEHAVIOR

### 2.1 Why the Unhardened Generator Failed

The unhardened generator in `scripts/generate-b2-2e-forensic-manifests.mjs` possessed two architectural flaws:
1. **Array Accumulation Without Candidacy Indexing:**
   ```javascript
   // FLAW 1: Emitted every profile occurrence directly into array
   const affidavits = [];
   for (const profile of mlaProfiles) {
     const cand = findCandidacy(profile);
     affidavits.push(createAffidavit(cand, profile));
   }
   ```
2. **Silent Default Coercion:**
   ```javascript
   // FLAW 2: Missing financial fields coerced to 0 via falsy fallback
   total_assets: profile.totalAssets || 0,
   total_liabilities: profile.totalLiabilities || 0,
   ```

### 2.2 Corrected Generator Design & Deduplication Architecture

The hardened generator implements strict candidacy indexing and type-safe disclosure handling:

```javascript
// ARCHITECTURE 1: Strict Candidacy Indexing Map
const affidavitByCandidacy = new Map();

for (const profile of mlaProfiles) {
  const candidacyId = matchCandidacy(profile);
  if (!candidacyId) {
    throw new Error(`FAIL-CLOSED: Orphan profile disclosure without candidacy: ${profile.name}`);
  }

  const existing = affidavitByCandidacy.get(candidacyId);
  if (!existing) {
    // Fresh candidacy disclosure registration
    affidavitByCandidacy.set(candidacyId, {
      id: generateAffidavitId(seq++),
      candidacy_id: candidacyId,
      person_id: matchPerson(profile),
      total_assets: profile.totalAssets != null ? Number(profile.totalAssets) : null,
      total_liabilities: profile.totalLiabilities != null ? Number(profile.totalLiabilities) : null,
      education: profile.education || null,
      profession: profile.profession || null,
      ...
    });
  } else {
    // Secondary auxiliary profile reconciliation
    // 1. Preserve verified non-null financials
    if (existing.total_assets == null && profile.totalAssets != null) {
      existing.total_assets = Number(profile.totalAssets);
    }
    // 2. Conflict detection: if both disclose different non-zero assets, WARN/FAIL
    if (existing.total_assets != null && profile.totalAssets != null && existing.total_assets !== Number(profile.totalAssets)) {
      console.warn(`DISCLOSURE CONFLICT for ${candidacyId}: ${existing.total_assets} vs ${profile.totalAssets}`);
    }
    // 3. Enrich auxiliary non-conflicting career attributes
    if (!existing.education && profile.education) existing.education = profile.education;
    if (!existing.profession && profile.profession) existing.profession = profile.profession;
  }
}
```
