## 4. CORRECTION B — CANDIDATE IDENTITY DEFECT FORENSICS

### 4.1 Person 6728 & The 13 Backslash Names Root Cause Analysis
During the initial manifest generation, 13 candidate names were observed ending in a trailing backslash (`\`), including Person 6728 whose entire display name was `\` (length 1), causing a violation of check constraint `char_length(canonical_name) >= 2`.

Forensic analysis of the generator script `scripts/generate-b2-2d-forensic-manifests.mjs` revealed the following regular expression:
```javascript
const runnerUpMatch = fileContent.match(/\brunnerUpName2022:\s*['"]([^'"]+)['"]/);
```
In TypeScript/JavaScript seed files, strings with single quotes or nicknames are authored with escaped single quotes (`\'`):
```typescript
// data/seed/gujarat-constituencies.ts, line 94:
runnerUpName2022: '\'Bajrang\' Hitendrakumar Bhagvanajibhai Patel'
```
Because the character immediately following the opening delimiter `'` was `\`, the character class `[^'"]+` captured only the single character `\` and terminated on the unescaped `'` of `\'`!

The defect was **100% in the manifest extraction transformation**, not corrupt upstream source data.
