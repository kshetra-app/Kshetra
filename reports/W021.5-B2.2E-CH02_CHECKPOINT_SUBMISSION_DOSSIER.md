## 4. SQL THREE-VALUED LOGIC & EXPLICIT NULL HANDLING (ITEM 4)

In standard PostgreSQL SQL, comparisons with `NULL` evaluate to `UNKNOWN`. In a `WHERE` clause, `UNKNOWN` conditions are treated as false. Consequently:
- `WHERE data_status <> 'OFFICIAL'` would **NOT** catch a record where `data_status IS NULL`.
- `WHERE criminal_cases < 0` would **NOT** catch a record where `criminal_cases IS NULL`.
- `WHERE state_code NOT IN (...)` would **NOT** catch a record where `state_code IS NULL`.

To guarantee absolute data integrity, the checkpoint artifact [`supabase/staging_checkpoints/w021_5_b2_2e_chunk_02_checkpoint.sql`](file:///c:/Users/Laven/OneDrive/Desktop/Kshetra/supabase/staging_checkpoints/w021_5_b2_2e_chunk_02_checkpoint.sql) was hardened with explicit `IS NULL OR ...` handling across all evaluated columns:
