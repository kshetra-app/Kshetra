## 7. Workstream B — Structurally Valid Markdown Tables

### 7.1 Pipe Escaping & Parsing Specification
To prevent unescaped pipes inside multi-AC administrative extent strings from splitting Markdown table cells into extra columns:
- **Encoding Convention:** All programmatic generators invoke `escapeMarkdownTableCell(value)`, converting literal `|` to `\|` and line breaks to `<br>`.
- **Parsing Convention:** `splitMarkdownRow(rowString)` steps character-by-character, respecting escaped `\|` as literal characters and splitting only on unescaped `|`.
- **Structural Invariants:**
  1. Header column count must match separator column count.
  2. Separator row syntax must strictly conform to `^\|?(\s*:?-+:?\s*\|?)+$`.
  3. Every data row must yield `cells.length === headers.length`.
  4. Rows with mismatched column counts are rejected with `[TABLE_PARSER_ERROR][COLUMN_COUNT_MISMATCH]`.
  5. Duplicate PIN rows are rejected with `[TABLE_PARSER_ERROR][DUPLICATE_PIN]`.
