## 4. Resolution of the PIN `500001` Discrepancy (Workstream A)

### 4.1 Investigation & Root Cause
- In the Directive 123 implementation report, the candidate list for PIN `500001` was written as `58, 59, 61` (Malakpet, Amberpet, Jubilee Hills).
- In the actual implementation code (`apps/api/src/services/delimitationService.ts`) and test fixtures, the candidate list was `[65, 63, 58]` (Goshamahal, Nampally, Malakpet).
- **Root Cause:** An editorial typographical error occurred during report authoring in Directive 123. The author incorrectly associated AC 61 with Nampally (Nampally is AC 63; AC 61 is Jubilee Hills) and included Amberpet (AC 59), which is geographically disjunct from central Abids / GPO.

### 4.2 Evidentiary Substantiation
Under Delimitation Order 2008 Schedule XXXI (Table B, Assembly Constituencies of Hyderabad District):
1. **Goshamahal (AC 65):** Encompasses GHMC Ward 78 (Gunfoundry), which contains the physical General Post Office (GPO) building at Abids, Troop Bazar, and adjacent commercial roads.
2. **Nampally (AC 63):** Encompasses GHMC Ward 10 and Ward 11 (part), encompassing Nampally Railway Station, Mozamjahi Market, and Asif Nagar, which are served by the 500001 delivery sub-beats.
3. **Malakpet (AC 58):** Encompasses GHMC Ward 3 (part) and Ward 17, adjoining Koti, Sultan Bazar, and Putlibowli along the north bank of the Musi River, where postal delivery zones cross the legislative constituency boundary.

### 4.3 Remediation Implemented
1. **Candidate Set Confirmed:** `[65, 63, 58]` is substantiated by Schedule XXXI concordance and retained in code and tests.
2. **Removal of Canonical AC:** `canonicalAcNo` on PIN `500001` was set to `undefined` (previously set to 65). Under Directive 124, an entry classified as `INTERSECTS_MULTIPLE_ACS` cannot claim a single canonical AC.
3. **Status Enforced:** Returns `status: 'AMBIGUOUS_CANDIDATES'`, `currentConstituency: undefined`, `proposedConstituency: undefined`, and candidate list `[{ acNo: 65, name: 'Goshamahal' }, { acNo: 63, name: 'Nampally' }, { acNo: 58, name: 'Malakpet' }]`.
4. **All Maintainers Aligned:** Source code, test assertions, audit ledger, defect register, and implementation reports are 100% synchronized.
